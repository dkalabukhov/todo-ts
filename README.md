This is a simple CLI program, which allows you to create and manage personal todos.

### Installation
If you don't have typescript installed globally:
```
npm install --global typescript
```
Install dependencies:
```
npm install
```
Then type tsc in the working directory:
```
tsc
```
Finally to start the program:
```
node dist/index.js
```

### Troubleshooting
If you have errors, then give to the program rights to create/remove/read/modify
files and directories.
The errors are informative and useful for debugging purposes.
